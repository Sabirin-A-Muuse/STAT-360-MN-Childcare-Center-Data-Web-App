About the Project

About MN Childcare Explorer

A simple way to explore Minnesota childcare center licensing data.

What is MN Childcare Explorer?

MN Childcare Explorer is a web-based data project designed to make Minnesota childcare licensing information easier to explore.

The application allows users to search for childcare centers, explore individual programs, and view summaries and charts based on the available public dataset.

Why was it created?

Childcare information can contain a large amount of data, which can make it difficult to understand at a glance.

This project organizes that information into a more accessible website so users can search, compare, and explore the data more easily.

Data Source

Minnesota Childcare Licensing Data

The data used in this project comes from Minnesota's public childcare licensing information. The dataset contains information about licensed childcare centers, including program names, locations, counties, license status, and licensed capacity.

The data was downloaded from the Minnesota Department of Human Services Licensing Information Lookup and included in this project for analysis and visualization.
